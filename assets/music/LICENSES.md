# Music licences

Every track the library uses, its licence and where to get it. Audio files aren't committed: download each
file into this folder under its `file` name (`curl -L -o assets/music/<file> <download>`), then run
`pnpm agentcast music analyze` if you change one.

CC0 tracks are public domain: no credit is needed, though crediting the artist is kind. CC BY tracks need the
credit in their `license` shown wherever a video using them is published.
